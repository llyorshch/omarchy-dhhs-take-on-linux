# Omarchy: DHH's take on Linux

Presentation built with [Slidev](https://sli.dev).

```bash
npm install
npm run dev     # local server at http://localhost:3030
npm run build   # builds into dist/
```

It is automatically deployed to [GitHub Pages](https://llyorshch.github.io/omarchy-dhhs-take-on-linux/) on every push to `main`.
